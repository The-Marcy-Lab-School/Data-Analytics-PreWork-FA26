2. From watching → interacting

Your first Scratch project mostly did something like this:

Green Flag → Character talks → Character moves → Scene changes

The audience watches.

Games and interactive stories add another possibility:

PLAYER DOES SOMETHING → PROGRAM RESPONDS

For example:

  • click a clue → evidence increases;
  • press a key → character moves;
  • answer a question → story changes;
  • collect an object → score increases.
Connection to data: A program can store information about what is happening. That information can then affect what happens next.

4. Your program needs memory

Imagine your player is investigating a data problem.

They collect one clue.

Then another.

Then another.

How does Scratch remember how many clues they collected?

We need a variable.

Variable: A named place where a program stores information that can change while the program runs.

5. Variables are data

You've already spent this course thinking about data. Now you're going to create data inside your own program.

evidence

Could store how many useful clues a player has collected.

Example value: 3

score

Could store how many points a player has earned.

Example value: 25

risk_level

Could represent how risky a situation has become.

Example value: 7

deliveries

Could track how many packages were successfully delivered.

Example value: 12

Assignment 1 connection: These values are data. A value like 3 is quantitative and discrete. In Python thinking, it would resemble an integer (int). Scratch handles values differently from Python, but the idea of storing information still transfers.

6. Create your first variable

  1. Open the Variables category.
  2. Click Make a Variable.
  3. Name the variable: evidence
  4. Choose to make it available for all sprites.
  5. Click OK.

You should now see an evidence display on your Stage.

when green flag clicked set [evidence] to 0
STOP & DO: Create the variable and make sure the Green Flag resets it to 0. Run your program more than once. It should return to zero every time.

9. You just created cause → effect

CAUSE

The player clicks the clue.

CODE

Scratch runs: change evidence by 1.

EFFECT

The stored value changes.

Programming idea #3: ACTION → DATA CHANGES

11. But our clue has a problem...

Right now, the player could click the same clue 100 times and collect 100 pieces of evidence.

That probably does not make sense.

One simple fix is to make the clue disappear after it is collected.

when green flag clicked show
when this sprite clicked change [evidence] by 1 say “Evidence collected!” for 1 seconds hide
TRY IT: Add hide after the clue is collected. Also add show underneath your Green Flag so the clue returns when the project restarts.

12. Add more data

Duplicate your clue sprite or add two new clues.

Give each clue code that increases evidence by 1.

Your goal:

3 clues → evidence = 3

STOP & BUILD: Create three clickable clues. Each clue should:
  1. respond when clicked;
  2. increase evidence by 1;
  3. give the player feedback;
  4. disappear after being collected;
  5. return when the Green Flag is clicked again.

13. Now Scratch needs to make a decision

Imagine the player needs three pieces of evidence before solving the case.

The rule is:

IF evidence is high enough → THEN solve the case

This introduces a condition.

Condition: A rule the program checks to decide whether something should happen.

14. Meet the IF block

if < evidence > 2 > then
say “We have enough evidence!” for 2 seconds

Read this like a sentence:

IF evidence is greater than 2, THEN say “We have enough evidence!”

If evidence is 0, 1, or 2, the condition is false.

If evidence is 3 or more, the condition is true.

15. True or false?

Suppose:

evidence = 2

Scratch checks:

evidence > 2

Is the condition true or false?

16. Add a “Solve Case” button

Add a sprite that acts like a button.

It might say:

SOLVE CASE

When the player clicks it, Scratch should check whether they have enough evidence.

when this sprite clicked if < evidence > 2 > then
say “Case solved!” for 2 seconds
else
say “Collect more evidence.” for 2 seconds
Programming idea #4: The same click can produce different results depending on the data stored in the program.

18. Why is this data analytics thinking?

COLLECT
