What Kind of Data Is This?

This reading helps you practice the three labeling lenses from Deck 2: what the data means, how quantitative data behaves, and how a Python program might represent it.

1. Three lenses, three different questions

Lens 1: Meaning

Qualitative or quantitative?

Does the data describe a category/status, or does it represent a count or measurement?

Lens 2: Behavior

Discrete or continuous?

If the data is quantitative, is it something you count or something you measure?

Lens 3: Representation

How might Python store it?

For this assignment, focus on str, int, float, and bool.

Important: these labels are related, but they do not mean the same thing. A piece of data can be quantitative, continuous, and represented as a float at the same time because each label answers a different question.

3. Numbers can fool you

ZIP code: 10001

It contains digits. Does that automatically make it quantitative?

Rule of thumb: if a number is being used as an identifier or label rather than an amount, it is not acting like quantitative data. ZIP codes, student IDs, and phone numbers are common examples.

4. Count or measure?

For this assignment:

Discrete

Think count.

Examples: 327 likes, 14 customers, 6 messages.

Continuous

Think measure.

Examples: 3.7 miles, 72.5°F, 12.8 seconds.

Try it: “Followers: 428”

5. The display can hide the concept

Weather app: 72°F

The app shows a whole number. Is temperature discrete?

Why? Temperature is measured and can take values between 71°F and 72°F. The app may simply round what it displays. Classify the concept being measured, not just the formatting you see.

9. One tricky example

Rating: 4.8 stars

Real datasets can represent ratings in different ways. For Assignment 1, what matters most is that you explain your reasoning.

One reasonable classification

Quantitative → Continuous → float can be a reasonable introductory classification if you are treating the displayed rating as a measured/averaged numeric value.

Why might real data work be more complicated?

Ratings can be collected as discrete individual scores, then averaged and displayed as a decimal. That means the original observations and the displayed summary may behave differently. This is exactly why context matters.
